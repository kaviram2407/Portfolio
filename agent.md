# Portfolio Tech Stack

## Core Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 15+ |
| Language | TypeScript |
| Styling | Tailwind CSS |
| UI Components | shadcn/ui |
| Animations | Framer Motion |
| Advanced Animations | GSAP + ScrollTrigger |
| 3D / Interactive Visuals | Three.js / React Three Fiber |
| Icons | Lucide React |
| Fonts | Inter / Geist |
| Deployment | Vercel |
| Version Control | Git + GitHub |

## Animation Stack

### Framer Motion
Use for:
- Page transitions
- Text reveals
- Cards
- Hover interactions
- Navigation
- Micro-interactions

### GSAP + ScrollTrigger
Use for:
- StarAir pipeline animation
- RAG pipeline animation
- Scroll-based storytelling
- Data flowing between architecture layers

### Three.js / React Three Fiber
Use sparingly for:
- Subtle hero/background experience
- Floating data nodes
- Interactive technology constellation

## Recommended Architecture

```text
Next.js
   |
   +-- TypeScript
   +-- Tailwind CSS
   +-- shadcn/ui
   |
   +-- Framer Motion
   +-- GSAP
   +-- Three.js / React Three Fiber
            |
            v
          Vercel
```

## Design Principle

Prioritize:

**Next.js + TypeScript + Tailwind CSS + Framer Motion + GSAP**

Use **Three.js sparingly** so the portfolio remains fast, professional, responsive, and visually impressive.
